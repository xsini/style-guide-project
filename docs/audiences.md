# Читатели и виды документов

| Читатель | Задача | Вид документа | Нужные подробности |
| --- | --- | --- | --- |
| Путешественник | Найти заявку и отправить отклик | Пользовательская инструкция | Условия, шаги, результат, ошибка |
| Автор заявки | Принять отклик и начать общение | Пользовательская инструкция | Статусы отклика и условие появления чата |
| Разработчик | Запустить и изменить прототип | README и описание архитектуры | Стек, команды, модель данных и localStorage |
| Проверяющий | Воспроизвести сценарий | Сценарий демонстрации и проверки | Демоаккаунты, последовательность и ограничения |

Автор заявки и путешественник обозначают участников сценария. Не представляйте их как две отдельные технические роли доступа без подтверждения в коде.

Пользователю объясняйте действие через интерфейс. Разработчику можно указать TripRequest, Response и localStorage. В одном документе допустимы отдельные разделы для разных читателей, если их задачи явно названы.
