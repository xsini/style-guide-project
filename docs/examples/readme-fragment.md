# Описание прототипа Travel Buddy Finder

Это пример вводного раздела README по сведениям отчёта ПР 10. Он описывает клиентский прототип поиска попутчиков. Проверка программного кода в рамках данного примера не выполнялась.

## Назначение

Travel Buddy Finder помогает показать сценарий поиска попутчика: пользователь заполняет профиль, создаёт заявку на поездку или находит чужую, отправляет отклик и получает доступ к локальному чату после принятия отклика автором заявки.

## Возможности описанной версии

- Демонстрационные регистрация и вход.
- Редактирование профиля путешественника.
- Создание, редактирование, закрытие и отмена заявки на поездку.
- Поиск заявок по параметрам поездки.
- Отправка, принятие и отклонение отклика.
- Локальный чат и уведомления в интерфейсе.

## Технологии и хранение

В исходном отчёте указаны React, TypeScript, Vite и React Router. Данные сохраняются в localStorage браузера. Сценарий с двумя аккаунтами воспроизводится последовательно в одном браузере с одним локальным хранилищем.

## Ограничения

Прототип предназначен для демонстрационных данных. Серверная часть, PostgreSQL, JWT, email- и push-уведомления, жалобы и модерация в описанную версию не входят. Сетевой обмен сообщениями и синхронизация между устройствами не подтверждены. Прототип не подтверждает личность попутчиков и не гарантирует безопасность поездки.

Порядок применения правил приведён в [протоколе редакторской проверки](validation.md).
