# Сообщения интерфейса и ошибки

## Состав сообщения

Сообщение называет ситуацию и следующее доступное действие. Не обвиняйте пользователя. Не показывайте трассировку стека и внутренние данные в пользовательской инструкции.

Следующие формулировки являются редакторскими рекомендациями. Они не выдаются за дословные сообщения существующего интерфейса.

| Ситуация | Рекомендуемый текст | Обоснование |
| --- | --- | --- |
| Неверные данные входа | Не удалось войти. Проверьте email и пароль | Понятное следующее действие |
| Дата окончания раньше начала | Укажите дату окончания не раньше даты начала | Объяснено правило |
| Отклик на собственную заявку | На свою заявку нельзя отправить отклик. Выберите другую поездку | Указано ограничение |
| Повторный активный отклик | Вы уже отправили отклик на эту заявку. Проверьте его статус | Не обещано создание дубликата |
| Чат до принятия отклика | Чат станет доступен после принятия отклика | Названо условие |
| Закрытая заявка | Заявка закрыта для новых откликов. Выберите активную заявку | Указан способ продолжить |

Сообщения об ошибке, пустом списке и успехе различайте по смыслу. Не используйте «Ошибка» для отсутствия результатов поиска: предложите изменить фильтры. При цитировании реального интерфейса сохраняйте его текст; предложение исправить интерфейс выносите отдельно.
