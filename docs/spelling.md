# Орфография и числовые данные

## Русский текст

Используйте букву «ё» последовательно. Основные кавычки — «ёлочки», вложенные — „лапки“. Имена файлов, код и команды сохраняйте без типографической замены символов. После короткого заголовка точку не ставьте.

## Даты и время

В повествовании пишите дату как 20.11.2026. В машиночитаемых примерах допускается ISO 8601: `2026-11-20`. Форматы не смешивайте без пояснения. Если действие зависит от времени, укажите часовой пояс: «18:00 по Москве (UTC+3)».

Не приписывайте приложению преобразование часовых поясов без проверки. Даты поездки приводите с годом, если иначе возникает неоднозначность.

## Числа и бюджет

Разделяйте разряды пробелом: 25 000. Десятичный разделитель в русском тексте — запятая. В коде сохраняйте синтаксис языка. Бюджет указывайте вместе с валютой, периодом и расчётной единицей, если они известны. Если валюта не определена продуктом, не подставляйте её самостоятельно.

Для диапазона используйте «от 10 до 15 дней». В командах не заменяйте обычный дефис типографским тире. Значение бюджета 0 не означает бесплатную поездку без соответствующего правила продукта.
