# Шаблоны документов

## Пользовательская инструкция

```text
# Название действия

Задача и область применения инструкции.

## Перед началом

Нужный аккаунт, состояние заявки, ограничения версии.

## Порядок действий

1. Первое действие.
2. Следующее действие.

## Ожидаемый результат

Наблюдаемое изменение состояния.

## Если действие недоступно

Причина и следующий шаг.
```

## Фрагмент README

```text
# Название проекта

Назначение и статус версии.

## Возможности

Функции, подтверждённые для описываемой версии.

## Запуск

Требования к среде и проверенные команды.

## Ограничения

Хранение данных, границы безопасности и нереализованные функции.
```

Команды запуска и версии инструментов обязательно сверяйте с package.json и фактической сборкой. Если кода нет, не выдавайте команды из отчёта за самостоятельно проверенные.

## Протокол проверки

```text
# Проверка названного сценария

Дата, версия, среда и исполнитель.

## Предусловия

Исходные данные и состояние приложения.

## Шаги и ожидаемый результат

Действия и наблюдаемое поведение.

## Фактический результат

Пройдено, ошибка или не проверено. Свидетельство выполнения.
```
